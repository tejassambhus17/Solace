Authenticated record counts were one check-in, one session and one reflection.
- **Fixed and retested · Explore.** In the 320×640 dark preview, Sleep filtered out breathing and restored after a tab switch. Searching for “five senses” returned two items. - **Fixed and retested · Solace.** At 320×568 dark, a 120-message synthetic saved chat opened with the newest turn visible and 12 message rows mounted. Older visible rows stayed in place after a tab switch, an appended reply and a smaller viewport. The composer remained visible. At 320×568 light, Voice Talk's text fallback saved into the same conversation. On the connected Android, a fresh synthetic send collapsed the artwork and displayed the labeled built-in reply, with the native keyboard used to enter the draft. Removing the isolated USB API forwarding caused a real failed send. The native composer kept the full draft and offered Retry. Restoring forwarding and retrying showed a reply. Reopening from history used the compact header.
- **Fixed and retested · responsive themes and avatar.** At 320×640, the five petal image sources and tile measurements matched in light and dark. On a 430×840 browser preview, Profile showed the intentional fallback for a new account, accepted a synthetic lotus image and restored it after reload.
- **Fixed and retested · navigation state.** At 320×640 dark, Today returned to the same 844 px offset after a tab switch and after Back from check-in. Journey retained the Month period and selected date. Explore returned to one visible root with the builder expanded. On Android, each tab exposed the correct selected state in light mode at 1.4× text with animator scale zero. The closing Profile content and final Today, Explore and Journey sections could scroll above the rail. The original phone appearance, font scale and animator scale were restored.

## Android performance

Used the same USB-connected 2312FRAFDI handset on Android 15, debug APK, synthetic account, dark system theme, 1.17× system text and 0.5 animator scale. The display is 1080×2400 px at 440 dpi, approximately 393×873 dp. For each unrecorded sample, visited each tab once, reset `dumpsys gfxinfo`, then injected 25 ordered taps through all five tabs using a 120 ms wait between input commands. Each run settled on Today. Gfxinfo reports different frame counts for the three samples, and these measurements include debug rendering.

| Sample | Rendered frames | Janky frames | Median | 95th percentile | PSS before → after |
| --- | ---: | ---: | ---: | ---: | ---: |
| Original `140db90` | 820 | 80 | 16 ms | 20 ms | 371,085 → 398,548 KiB |
| UI changes with remounting | 27 | 27 | 350 ms | 600 ms | 392,751 → 425,952 KiB |
| Final lazy retention and safe area | 117 | 77 | 23 ms | 150 ms | 366,124 → 416,450 KiB |

The intermediate build still hit a 250 ms median with animator scale zero. Android frame timestamps put the largest stalls before traversal, while the GPU percentile was 8 ms. The final implementation mounts Today, Explore, Journey and Profile on first visit, keeps their views and scroll state, and suspends their effects when hidden. Each receives its own route snapshot. Chat and immersive screens still unmount on navigation to keep voice, timer and media cleanup bounded. The final sample improved on the remounting build. It still lagged the original debug baseline, and a longer memory trace and release-mode performance comparison remain open.
