# Solace nested screen redesign

Inventory traced from `App.tsx`, `src/routes.ts`, the retained stacks in `src/store.tsx`, `src/experience-links.ts`, `src/widget-links.ts`, the Today and Explore cards, Journey menus and saved records, and Profile links. The same route can belong to several tab stacks. Aliases and route states are grouped where they render the same experience. The frozen before bundle is `work/four-tab-sweep/final-web`. Browser captures are evidence of the rendered app with fixture accounts.

The existing app and `design/references/00-home-tabs-{dark,light}.png` set the direction. Use real nature imagery where it gives the activity a sense of place. The wellness library should feel curated. Practice timing and writing need quieter, purpose-built compositions. Journey should read as a personal archive, and settings should make identity, preferences, and controls easy to scan. Black is the dark canvas. Warm light belongs to artwork, and lavender signals selection or action.

`src/NestedDesign.tsx` provides `SceneIntro` and `EditorialSection`. It reuses the existing semantic color, typography and spacing tokens and packaged artwork. Screen-specific compositions add the saved-practice shelf, classic breathing stage, sense itinerary, reading surface and archive. The shared Back control and safe-area ScrollView use existing UI primitives. Android rail labels now fit their cells when enlarged. The rail keeps its tap, drag and spotlight behavior.

Classic Five Senses retains its five self-paced steps and existing completion model. The guided grounding and sleep players use the existing timed ambience system. Sleep Wind Down remains a separate checklist guide. No synthetic activity statistics or sample personal records were added to the application.
